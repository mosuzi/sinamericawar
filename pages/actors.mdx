# 周边与域外态势

## 这张地图上不只有中美

台海战争不会只由中美两国的总兵力决定。日本和菲律宾提供前沿地理位置，朝鲜半岛会吸走原本可用于台海的预警、防空与地面力量，俄罗斯拥有把冲突推向核升级的能力，越南和东盟控制着重要航道与政治回旋空间，欧洲则更可能通过金融、贸易、军工和远洋支援影响战争长度。

本页把这些力量分成三层：**直接战区、印太支援圈、欧洲域外力量**。数字是2024—2026年公开资料基线，不是对2027年的精确预测；“军费”统一优先采用SIPRI的2024年日历年口径，“GDP/人口”统一采用世界银行2024年口径。台湾地区使用其统计机构资料，朝鲜因缺乏可比国民账户与预算资料留空。

## 第一层：直接战区

### 台湾地区：兵力不小，纵深和能源最紧

日本防卫省依据《Military Balance 2025》等资料汇总的公开估计是：台湾地区总兵力约**17万人**，其中陆上兵力约9.4万人；约150艘舰艇、总吨位约21万吨，含4艘潜艇；作战飞机约420架，其中约322架属于第四代战斗机。数字包括能否妥善维护、及时出动并在首轮打击后继续作战等未知因素，不能按件数直接计算战果。

2024年台湾名义GDP约**7969亿美元**。SIPRI估计其2024年军费为165亿美元；台湾防务部门另称，按北约扩展口径计算的2026年防务预算为**9495亿新台币、约占GDP 3.32%**，两者因年份和是否计入海巡、退役给付及特别预算而不可直接比较。

真正的战略约束包括：

- 岛屿防御有海峡这一道天然屏障，却缺乏后方纵深，机场、港口、电网和通信系统都要承受持续压力。
- 2025年官方能源统计显示，能源供给中进口约10.859万千公秉油当量、自产约5274千公秉油当量，进口占比约**95.4%**。封锁即使没有完全切断航运，也会迅速改变保险、库存和发电调度。
- 美国《台湾关系法》要求提供维持足够自卫能力所需的防务物资，并要求美国保持抵抗武力或胁迫的能力；它**不是写明自动出兵的共同防御条约**。是否直接参战仍取决于总统、国会、战场事件与盟友协商。

**小说中的边界：** 台湾是战争目标和主要承受者，不被写成只等待援军的棋盘。防空、后备动员、基础设施修复、医院与地方治理决定抵抗能维持多久。

### 日本：最可能被地理和基地拖入战争

2025年日本防卫白皮书的统一口径列出：陆上兵力约**13万人**，海上力量139艘、约53万吨，作战飞机约370架。日本2025年度防卫力整备计划相关支出为**8.4748万亿日元**；SIPRI的2024年日历年可比口径为553亿美元。

日本的优势是反潜、防空、预警、先进战斗机、岸基导弹以及与美军高度互操作；弱点是西南岛链和大型基地靠近战区，弹药、掩体、跑道修复和民众疏散都构成现实约束。

法律上，《日美安全保障条约》第五条针对的是“**日本施政下的领土**”内对任何一方的武力攻击，并不把台湾本身写入自动适用范围。台海危机可以先触发第四条磋商、基地使用、情报与后勤支援；若日本领土、自卫队或驻日美军遭到攻击，参战门槛才会明显降低。

经济上，日本财务省统计显示，2024年日本对华出口约**18.86万亿日元**、自华进口约**25.31万亿日元**，双边货物贸易合计约44.18万亿日元。安全同盟把日本拉向美国，产业链和市场损失又会持续给东京施加停火压力。

**小说中的边界：** 本书采用一条更高风险的虚构分支：日本内阁把伴随武力的海上封锁认定为可能构成“存立危机事态”，在本土尚未遭受攻击时便主动派遣自卫队进入封控区外围，并通过护航、高风险接触和扩张性自卫解释首先成为外部交战国。它仍不是“台湾有事自动宣战”，而是日本政府主动制造国内法与舆论可以接受的参战条件。

### 朝鲜：数量、导弹和不可预测性

日本防卫省的2025年公开汇总估计朝鲜总兵力约**128万人**，其中陆上兵力约110万人；约785艘舰艇但总吨位仅约10万吨，作战飞机约550架。大量舰机技术较旧，然而前沿炮兵、地下化设施、特种作战力量和不断发展的弹道导弹仍能迫使韩国、日本与驻韩美军保留大量防御资源。

SIPRI对2026年1月的估计是朝鲜可能已经组装约**60枚核弹头**，裂变材料最多可支持约90枚；SIPRI同时强调不确定性很大。核武数量小于中美俄，不等于风险小——在预警时间短、指挥体系封闭的半岛，误判代价反而更高。

2024年俄朝《全面战略伙伴关系条约》第四条规定，一方因武装侵略进入战争状态时，另一方应依各自法律和《联合国宪章》第51条立即提供军事及其他援助。条文仍需对“侵略”和“战争状态”作政治解释，但它已经把俄朝关系提升到具有相互军事援助义务的层级。

**小说中的边界：** 朝鲜不是接受北京命令后行动，而是借日本参战实现自身威慑和牵制目标；其参战首先迫使日韩美分兵，并给下一阶段俄方介入制造条约与安全借口。

### 韩国：强军却最不愿开第二战场

同一公开口径估计韩国总兵力约**50万人**，陆上兵力约37万人；约230艘舰艇、28万吨，作战飞机约570架。驻韩美军约3万人、拥有约80架作战飞机。韩国装备有F-35、F-15K、F-16、K2坦克、K9火炮、宙斯盾驱逐舰和常规潜艇，质量明显高于朝鲜大量旧式平台。

韩国国防部公布的2026年防务预算为**65.8642万亿韩元、约占GDP 2.37%**；2024年SIPRI可比口径为476亿美元、占GDP约2.56%。它的最大限制并非装备，而是首尔都市圈距军事分界线很近，任何台海增援都必须先问：朝鲜是否会利用兵力空缺。

美韩同盟保护韩国，但不意味着韩国必须因台湾事件主动对华开战。平壤一旦进入最高战备，首尔更可能将主力留在半岛，限制驻韩美军被抽调，并通过外交渠道阻止俄朝联动升级。

**小说中的边界：** 韩国保持武装中立式防御，拦截针对本国的攻击并保卫美军基地，却不主动攻击中国；它在停火谈判中最优先处理朝鲜炮兵和导弹后撤。

### 俄罗斯：账面庞大，能到远东的才算数

日本防卫省依据2025年资料估计俄罗斯总兵力约**113万人**，陆上兵力约61.5万人；全国海军约1180艘、201万吨，含51艘潜艇；作战飞机约1387架，并拥有战略轰炸机。这里是全国口径，不能视为太平洋舰队和远东军区可即时投入西太平洋的数量。

SIPRI估计俄罗斯2024年军费为1490亿美元、约占GDP 7.05%；2026年1月核武总库存约**5420枚**，其中约1796枚处于部署状态。核力量和远程航空兵使俄方即便只有限介入，也能迫使美日重新分配预警、反潜和防空资源。

中俄关系高度紧密，但中国外交部在2026年仍将其原则表述为“**不结盟、不对抗、不针对第三方**”。《中俄睦邻友好合作条约》要求受到威胁时立即接触磋商，却不是北约式自动共同防御条款。因此，俄方参战需要自身利益、俄朝条约或本国部队遭攻击等另外理由。

**小说中的边界：** 俄罗斯先提供能源、铁路运力、态势信息和商船护航；在俄日部队发生交火后，才以保护本国航行与安全为由有限参战。它造成的是北向压力和核风险，不是凭空变出第二支跨海登陆大军。

## 第二层：印太支援圈

### 菲律宾：军力较小，位置极重

菲律宾2024年军费约61亿美元。其政府文件显示，2025年武装部队预算约**2642亿比索**，2026年拟增至2869亿比索。重点是陆、海、空现代化、海岸监视、基地和飞机维护，而不是与中美海空军进行对称决战。

菲律宾与美国有1951年《共同防御条约》，并向美军开放**九处EDCA商定地点**。美菲公开声明把条约适用表述为：在南海任何地点对两国武装力量、军机和公务船舶（包括海警船）的武装攻击。台湾本身并不自动触发该条约，但吕宋北部靠近巴士海峡，使菲律宾机场、港口和传感器在疏散、搜救、补给和态势感知上极具价值。

经济牵制同样明显。菲律宾统计局称，2024年上半年中国提供了菲律宾**25.4%**的进口商品，是其最大进口来源。马尼拉既担心南海安全，也难以忽略战争对制造业投入品、物价和就业的冲击。

**小说中的边界：** 菲律宾允许EDCA设施用于基地防护、撤侨、搜救和补给，但在本国未受攻击时限制从其领土直接发动对华打击；它是关键支点，不被夸写成主力舰队。

### 越南：有争议，也有“四不”

日本防卫省的统一估计把越南陆上兵力列为约**38万人**，规模居世界前列。越南拥有以近海防御为主的护卫舰、常规潜艇、岸基导弹和防空体系，但装备来源复杂、公开预算有限，持续远海作战能力不宜高估。

越南2019年国防白皮书确立“四不”：不参加军事联盟，不联手一国反对另一国，不允许外国设立军事基地或利用越南领土反对他国，不在国际关系中使用或威胁使用武力。越南与中国存在南海争议，同时又保持密集的党际、经贸和供应链联系。

**小说中的边界：** 河内提升沿海戒备、保护本国海上权益并参与东盟斡旋，但拒绝开放基地供任何一方攻击第三国。越南的价值在于守住战略自主并维持一条外交出口。

## 第三层：欧洲与北约

### 先纠正一个常见误区：北约不会因台湾自动启动第五条

北约官方解释明确指出，《北大西洋公约》第六条对第五条共同防御义务设有地理限制，核心范围是北回归线以北的北大西洋区域。台湾遭攻击本身不在这一自动适用范围内。欧洲盟国仍可依据各自国内法、双边协定或联合行动提供支援；若欧洲成员国本土、条约范围内的舰机或其他明确受保护对象遭攻击，法律判断才会改变。

因此，“欧洲参战”更可能从以下台阶逐步升级：外交谴责与撤侨，出口管制和金融制裁，情报与后勤共享，远洋护航，个别国家有限军事支援，最后才是直接交战。欧盟不是拥有单一战争指挥权的国家，27国决策速度和风险偏好也不会一致。

### 英国：远洋能力完整，规模是硬约束

英国2025年10月共有约**18.21万名军职人员**，其中正规军约13.71万人、志愿预备役约3.19万人。2025年装备统计列出70艘海军与辅助舰船，包括4艘战略导弹核潜艇、5艘攻击核潜艇；固定翼飞机504架，其中记录“在役”状态的371架里有304架在役。

英国拥有两艘“伊丽莎白女王”级航母、F-35B、攻击核潜艇、远洋补给与“五眼”情报体系，也有全球承诺和人员不足问题。SIPRI对2026年1月的估计仍是**225枚核弹头**。

**小说中的边界：** 英国可提供情报、潜艇与海上护航，或把航母编队作为政治信号；但跨越半个地球维持高强度出动会迅速碰到护航、弹药和补给上限。

### 法国：太平洋不是纯粹的“域外”

法国2024年国防部军职人员约**19.96万全职当量**，在新喀里多尼亚和法属波利尼西亚分别部署约2200和1000名主权部队。法国还拥有一艘“戴高乐”号核动力航母、核攻击潜艇、阵风战斗机和全球基地网络。

SIPRI估计法国2026年1月核武总库存约**370枚**；法国政府已减少公开核库存细节，数字应视为外部估计。法国在印太拥有本国公民、领土和专属经济区，因此会比多数欧洲国家更直接关注航行安全，却仍须兼顾欧洲方向和战略自主。

**小说中的边界：** 法国先保卫海外领地、撤侨和护航，再决定是否参与美国主导行动；它可以是独立外交渠道，而非自动跟随者。

### 德国与欧盟：经济战场比舰队更大

德国联邦国防军在2026年7月约有**18.67万名军人**。其2024年军费885亿美元，在欧洲名列前茅，但主要规划、基地和陆军重心仍在欧洲，短期内向西太平洋投送大规模持续作战力量并不现实。

欧盟27国2024年防务开支合计**3430亿欧元、占GDP 1.9%**，其中装备采购880亿欧元、研发130亿欧元。它代表巨大的财政与工业潜力，却分散在不同国家、军种和采购体系中。

欧盟与中国2024年货物贸易额约**7320亿欧元**；欧盟自华进口5178亿欧元、对华出口2133亿欧元，逆差3045亿欧元。战争将把制裁、关键技术出口、航运保险、汽车与机械供应链、消费品价格同时变成国内政治问题。

**小说中的边界：** 德国和欧盟主要通过制裁、出口管制、军工增产、人道援助和外交调停介入。若没有欧洲自身遭攻击，把欧盟写成整齐划一地派出“远征军”反而不可信。

## 外交态势：谁有义务，谁有选择

| 关系 | 公开文件能确认什么 | 不能自动推出什么 |
| --- | --- | --- |
| 美台 | 《台湾关系法》支持自卫能力并要求美国保持抵抗武力胁迫的能力 | 没有写明台湾遇袭后美国自动宣战 |
| 美日 | 第五条覆盖日本施政下领土内对任一方的武力攻击；第六条允许美军使用日本设施 | 台湾本身不属于第五条写明的条约领土 |
| 美韩 | 共同防御核心是韩国与太平洋区域安全，驻韩美军形成强绑定 | 韩国不会因台海冲突自动把半岛主力调走 |
| 美菲 | 条约与近年联合声明覆盖南海对军队、军机和公务船舶的武装攻击；EDCA有九处地点 | EDCA不等于美国拥有菲律宾基地，也不等于可不经马尼拉同意对华开战 |
| 俄朝 | 2024年条约包含遭武装侵略进入战争状态时的相互军事援助 | 如何认定“侵略”以及援助规模仍由政治和国内法决定 |
| 中俄 | 高水平战略协作，受威胁时有磋商机制 | 中方公开定位仍是不结盟，不存在北约式自动共同防御条款 |
| 北约 | 成员遭符合第五、六条的武装攻击并请求集体行动时产生援助义务 | 台湾冲突本身不在北约第五条的地理自动适用范围 |
| 欧盟、东盟 | 能协调制裁、贸易、人道、航运和外交立场 | 不是可以一键投入战场的单一国家军队 |

## 经济冲击怎样反过来改变战局

1. **能源和航运先于GDP总量发挥作用。** 台湾的高进口能源依赖、日本和韩国的海运能源体系，以及东亚对马六甲—南海—巴士海峡航路的依赖，会使保险费、改道和库存天数迅速成为军事变量。
2. **制裁是双向成本，不是免费武器。** 欧盟对华货物贸易达7320亿欧元，日本对华货物贸易约44.18万亿日元，任何全面禁运都会同时打击企业、消费价格与盟友团结。
3. **半导体冲击不止发生在台湾。** 芯片制造依赖台湾生产、美国软件与设备、日本材料、欧洲光刻系统以及跨国封装测试；破坏任何一环都可能让汽车、通信、武器和电网设备同时缺货。
4. **军费只显示投入，不显示库存。** 造船、导弹、拦截弹、航空发动机和维修技师的补充周期以月或年计算。战争持续越久，工业产能、盟友标准和港口维修越比首日平台数量重要。
5. **金融与海运规则能扩大或缩小战区。** 美元结算、欧洲保险、亚洲港口准入和出口许可证可以把没有开火的国家卷入经济战，也可以成为交换停火的筹码。

## 对小说情节的直接约束

- 维持既定参战顺序：**日本 → 朝鲜 → 俄罗斯 → 美国**。这里的“参战”仅指直接使用武力；美国、日本盟友和欧洲在正式开火前已经通过情报、后勤、基地、撤侨、外交或经济措施深度介入。
- 日本在本土未遭打击时主动进入封控区，并首先把高风险接触升级为交火；中国前期只在外海反击，以避免立即触发日美共同防御最清晰的适用情形。
- 俄罗斯因日本检查俄方护航船队并发生俄日交火而有限进入，而不是虚构一项不存在的中俄自动参战条约。
- 朝鲜的主要军事效果是牵制日韩美资源、提高核风险；韩国的首要目标是阻止半岛全面开战。
- 菲律宾的作用以基地防护、搜救、撤侨、态势感知和有条件后勤为主；越南保持“四不”并推动东盟斡旋。
- 英法保留远洋和核威慑存在，欧盟主要打经济与工业战。它们会改变战争成本，但不会突然在台湾附近出现一支规模不受后勤约束的“欧洲联合舰队”。
- 美国从战争开始即向日本提供情报和后勤，却因台湾率先推动法理变化、日本未经协调扩大冲突而拒绝直接开火；直至美军自身遭到有意打击才成为最后一个直接参战的大国。
