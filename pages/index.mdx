# 序

![《海峡尽头：2027 中美战争》封面插画：雨夜海峡、远处舰影与一副受损的值更耳机](/illustrations/cover.png)

海峡并不宽。晴天里，人们可以从一侧想象另一侧的灯火；在地图上，它更像一道伸手就能越过的蓝色折痕。可真正堆积在水面上的，是几十年的记忆、承诺、恐惧与互不相让。它们没有哪一件能够被导弹击沉，也没有哪一件会因为一纸命令自行消失。

《海峡尽头：2027 中美战争》从一句越过政治红线的演说写起。随后，一份泄露的对外联络纪要把台海推入倒计时；东京、平壤、莫斯科和华盛顿又被各自的同盟、焦虑与误判拖向战场。纸面上最强大的军队最终发现，决定战争长度的不只是舰艇、飞机和导弹，还有距离、补给、工业，以及谁肯在核门槛前先停一步。

我想写的并不是一张不断扩大的战果表，而是命令离开会议室以后发生的事：雷达屏幕上的光点怎样变成某个家庭迟迟等不到的电话；远在海外的人如何借一段视频维持权威；胜利者又怎样面对停火、接管、审判和漫长的日常生活。所谓“最后一战”，真正困难的从来不是开始，而是让它成为最后一战。

这是一部架空小说，不是战争预测。赖清德与唐纳德·特朗普使用现实人物姓名，但书中的演说、秘密协商、境外转移、战争决策、对话与战后处置均属虚构；其余军政人员和平民角色亦为虚构。真实单位、舰艇、舷号、番号及装备型号只用于营造时代背景，故事中的2027年编组、部署、命令、交火、损伤和伤亡均为小说设定。

读者不必先读资料，可以直接从[序章：一句话变成倒计时](/story)进入故事。小说完结之后，站内另附[公开兵力与资料口径](/forces)和[周边与域外态势](/actors)，说明创作采用的公开基线及其局限；事实、虚构与写作边界则见[关于本书](/about)。
