# 《海峡尽头：2027 中美战争》插画制作基准与场景清单

## 统一视觉基准

- **用途：** 小说站点章节题图、项目内视觉设定与竖版封面。
- **画风：** 近未来战争纪实数字绘画；写实比例与可信材质，保留克制的绘画笔触和轻微胶片颗粒，不做照片拼贴，也不做游戏宣传海报。
- **主色：** 海雾蓝灰、深海军蓝、钢铁灰；只用警报红、甲板灯、抢修灯和医院应急灯形成少量琥珀色强调。
- **气候与空气：** 2027 年东亚春季，潮湿、海雾、细雨、低云、盐雾与室内长期封闭后的轻微浑浊感。
- **叙事立场：** 画面关心“人在系统与命令中的位置”，武器是环境和压力来源，不把毁伤画成奇观，不使用胜利姿态、宏大旗帜墙或英雄式仰拍。
- **共同限制：** 不表现血腥细节；不添加正文没有的人物或决定性战果；不出现可读战术坐标、攻击参数和现实行动路线；不出现水印、品牌标志、额外文字或宣传口号。
- **章节题图画幅：** 横向 3:2，主体避开最外侧边缘，兼顾桌面和移动端裁切。
- **封面画幅：** 竖向 2:3，上方和中上部留出标题空间；图内不直接生成书名，文字由站点排版承担。

## 生成与验收

1. 先生成 R01—R03 并逐张检查；章节题图必须引用相关基准图，人物不得重新设计。
2. 章节题图按 S00—S15 顺序生成；每张只画一个明确瞬间，不做漫画分格或宣传拼贴。
3. 逐图检查舰艇/飞机时代感、制服阵营、人物动作、光色和禁用项；发现漂移时只做单项修正。
4. C01 最后生成，复用全套光色与“耳机—海峡—灯光”母题，不直接复刻任一战斗场面。
5. 最终文件置于 `public/illustrations/`，章节以站点 `basePath` 下的 `/docs/illustrations/...` 路径引用。
